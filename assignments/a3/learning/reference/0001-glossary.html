术语卡：输入与状态

词 ID：词表中的整数索引。Embedding：由词 ID 查表得到的向量。Hidden state：当前步计算得到、结合上下文的内部表示。Tensor shape：每一个轴的长度。

B：批内句子数；T：补齐后的序列长度；D：词向量长度；H：隐藏状态长度。轴的排列不是固定的，必须看实现约定。

标准 LSTM 另有 cell state：通过门控制保留与写入的信息通道。hidden state 是经输出门调节的 tanh(cell state)，不是词概率，也不能简单理解成只保存短期信息。详解留给后续课。
