一个词，如何变成“读到这里”的状态？

本课目标：分清输入词向量与 hidden state，并能解释一个三维张量的每个轴。暂不记 LSTM 门公式。

主阅读：RNN 课件 PDF 第 26–27 页。图上紫色是词向量，红色是 hidden state；横向箭头是信息随时间传递。

1 · 同一个词，两种表示

读“我 喜欢 电影”。词 ID 是查表用的编号；embedding 是这个词查到的一串数字。同一份 embedding 表中，同一个词查得同一向量。

RNN 每步同时接收当前词向量和上一步状态，计算新的状态。读到“电影”时，状态既受“电影”影响，也受前面的“我 喜欢”影响。它是可学习的上下文表示，不保证完整记住所有信息。

上一步状态 hₜ₋₁ ─┐
                  ├─ 同一套更新规则 → 当前状态 hₜ
当前词向量 eₜ ───┘

因此，“我 喜欢 电影”和“我 讨厌 电影”中的“电影”词向量相同，读到它时的状态则可能不同。不同时间步共享模型参数，不是共享同一个状态值。

课件式子：hₜ = σ(Wₕhₜ₋₁ + Wₑeₜ + b)。现在只读含义：分别变换旧状态和新输入，相加，再经过非线性函数 σ；此处 σ 是课件的泛指，不必认定为 sigmoid。

2 · 三个轴，各回答一个问题

假设一次处理 B=2 句话，每句补齐到 T=3 个位置，每个词用 D=4 个数表示。我们本课约定 batch 在最前：

X.shape = (2, 3, 4) = (B, T, D)
轴回答的问题
B = 2哪一句话？
T = 3句子中哪个位置？
D = 4该词向量的哪个分量？

下标从 0 开始。X[0, 1, :] 取第一句的第二个词，保留它全部 4 个分量，形状是 (4,)。冒号表示“这个轴全部保留”。

X[:, 1, :] 同时取两句话的第二个词，形状是 (2, 4)。如果 hidden size H=5，那么两句话在一个时间步的状态形状是 (2, 5)，收集三个时间步则是 (2, 3, 5)。D 与 H 可以不同。

这里是单层、单向 RNN 的教学形状，并不是对 A3 实际布局的断言。A3 的双向编码器和 PyTorch API 可能采用不同轴序，后续逐项核对。

3 · 先回忆，再展开核对

① X 的形状为 (2, 3, 4)。X[1, :, :] 取的是什么，形状是什么？

查看反馈

第二句话的全部三个词向量，形状 (3, 4)。整数索引去掉 batch 轴；两个冒号保留后两轴。

② hidden state 长度为 5，是不是表示模型只能记住 5 个词？为什么？

查看反馈

不是。5 是表示空间的分量数，不是 5 个词的存储槽。模型把上下文编码到这 5 个数里，这种表示可能丢失信息。

③ 两个句子的当前词相同，hidden state 是否必然相同？

查看反馈

不必然。相同词的 embedding 相同，但先前状态可能不同，新状态由两者共同决定。
